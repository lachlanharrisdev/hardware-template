# {Project}

A repository template for hardware projects.

## Structure

`assets/` contains demonstration images, videos and other multimedia used for
secondary, illustrative or demonstrative purposes

`cad/` contains files for any technical drawing, 3D modelling, testing,
simulation, EDA (Electronic Design Automation) or ECS (Electronic Circuit
Simulator) software, including LTspice files.

`docs/` contains the BOM (Bill Of Materials), progress journal, and project-
specific documentation.

`src/` contains firmware files and any scripts or files only used by the
firmware or in the firmware development process.

`pcb/` contains CAD files specifically for PCB designs, especially KiCad files.
